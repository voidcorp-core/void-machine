# Dogfood through an isolated source self-host artifact

## Context

Running consumer `init` in the harness repository would merge or overwrite
authored `CLAUDE.md`, `AGENTS.md`, native runtime configuration and core assets.
Testing only the committed package mirror would also miss drift in current
TypeScript sources.

## Decision

The source repository compiles both runtime adapters into the gitignored
`.void/machine/generated/current` boundary. Compilation starts in a uniquely owned
`.staging-*` directory and atomically swaps the complete artifact. A
deterministic receipt binds current source inputs, rollout mode, file hashes and
modes.

The hook bundle is built from current TypeScript with the checkout's esbuild,
resolved from the source repository rather than bundled into the published CLI.
Self-host doctor exercises discovery, both adapter hook smokes, canonical event
writing and replay. Native runtime executables are reported independently:
absence is degraded, not certified and not a structural release blocker.

Rollout modes are `shadow`, `warn`, `enforce`, and `release-gate`. The first two
are advisory. The latter two fail on missing, stale, drifted or non-executable
artifacts.

## Consequences

Positive:

- The harness consumes current sources without confusing them with published
  mirrors or taking ownership of maintainer runtime configuration.
- Idempotency, source drift and rollback are executable contracts.
- CI can gate the exact source-to-runtime compilation path account-free.

Negative:

- Source self-host requires the repository development dependencies, including
  esbuild; it is intentionally unavailable in an arbitrary consumer checkout.
- Runtime availability alone does not prove a native agent invoked the hook.
  Full native certification remains a separate runtime lane.

## Alternatives considered

- Run consumer `init --force` at repository root: rejected because it can seize
  or rewrite authored and user-owned native files.
- Reuse only `packages/core/hooks/_void-hook.mjs`: rejected because stale
  generated bytes could hide changes in hook-runner TypeScript.
- Commit the self-host artifact: rejected because platform-generated bytes and
  local runtime evidence are not source.

## Reversal cost

Low. The generated boundary is disposable; the compiler and receipt schema can
be replaced without migrating consumer installations.
