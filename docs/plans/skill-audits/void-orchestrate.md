# void-orchestrate source audit

Sources are recorded beside the skill. Official Herdr 0.9.0 client/server protocol 22
and CLI captures informed the recipe; no upstream prose was vendored. The installed
runtime recipes were checked before the approved DEV-1016 plan.

## Adaptations

Native short contexts keep the runtime's real IDs. Durable workers use Herdr and
central files owned by ORCH/worker, with atomic replacement. Label plus canonical
worktree replaces a remembered pane ID. Bounded strict YAML and explicit failure
states make interruption and stale reports visible. Existing canonical review
receipts bind exact commit/base/criteria independently of worker status.

## Rejections

No mandatory Agent interception, team kernel launch, resident process, global config
rewrite, arbitrary metadata purge or central report as independent proof. No claimed
resume_argv support before 0.9.2. No server restart or runtime upgrade as a fallback.
The legacy run collector remains for already-admitted runs; permissions and merge
policy remain their existing owners' responsibility.

## Verification

Skill contract tests cover recipes, bounded size, continuity and provenance. Source
assets are derived through the registry. Real restart/Cortex conformance was outside
the authorized test scope; ORCH owns controlled real projection and final review.
