# Accepted scope

Explicit conversation approval: simplify the audited development workflow to save consumer time,
retain TDD before behavior, KISS/SOLID, primary domain specialist advice, security and useful
independent review. Avoid improvement loops that cannot change the requested result.

## Acceptance

- A clear authorized request proceeds without repeated spec/plan/ticket approval.
- Changed coding domains invoke the smallest pertinent expert set before implementation.
- Actual RED-before-production and GREEN, configured checks and security remain required.
- Optional nits, harmless missing prose and universal numeric targets do not create new loops.
- UI, integration and architecture work is scoped to the affected contracts and risks.
- Review remains one independent general pass and bounded targeted correction; runtime diversity
  is preferred honestly without pretending canonical dispatch supports a different source.
- Shipped skill mirrors and generated references match authored source; contract tests pass.

## Boundaries

No controller rewrite, permission change, weakened hook or remote CI, automatic migration,
consumer upgrade or release. The simple cheatsheet and per-ticket execution recap are recorded
for the subsequent step, per the user's explicit sequencing; no external telemetry integration.
